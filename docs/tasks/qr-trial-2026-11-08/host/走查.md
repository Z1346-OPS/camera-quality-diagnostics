# QR 内容核验走查单（主持人用）

本轮使用同一张合成图片、同一整图区域和同一套解码设置。目标是观察参与者如何判断读出内容的正确性。真人走查待完成。

## 现场发放

1. 在助手仓库 `D:\AIProjects\projects\test_failure_investigator` 用 PowerShell 运行 `.\.venv\Scripts\python.exe -B -X utf8 .\src\run_investigator.py`。每人从新窗口开始，给匿名代号，如 Q01。
2. 只发 `round-1` 目录。参与者导入主报告，按任务卡作答。记下原话、引用字段、用时和求助点，保存为 `Q01-R1.md`。第一轮答案留存后再发 `round-2`。主持人保管参考说明和评分依据。
3. 参与者在同一调查追加第二份报告，再回答同一个问题并另存 `Q01-R2.md`。先记录独立回答，再请其指出哪条证据改变了判断。如有独立接手人，按轮次只给交接说明，记录他能否找到支持结论的字段。

本机 `data/reports/qr-trial-5580928d08/` 已备好 `round-1.zip`（任务卡、01.json）和 `round-2.zip`（02.json）。按上述顺序分别发放并解压。其他检出可直接使用仓库内的两个 `round-*` 目录。

## 判读依据

| 问题 | 第一轮：[01.json](../round-1/01.json) | 第二轮：[02.json](../round-2/02.json) |
| --- | --- | --- |
| 这次执行和解码得到了什么？ | `status=completed`，整图 `decode_summaries[0].decode.status=decoded`，单一有效符号。 | 同一图片、整图区域和解码配置，也得到一个有效符号。 |
| 有独立答案吗？ | `known_truth.status=not_provided`。 | `known_truth.status=provided`。来源为生成该样例前固定的 UTF-8 文件，摘要在 `known_truth.sha256`。 |
| 能否确认内容正确？ | `decode_summaries[0].truth_check.status=not_provided`。只确认读出了二维码；内容是否正确仍未知。需要独立于本次解码的已知答案。 | 同一字段为 `correct`，`comparison=exact_payload_bytes`。这次整图读出的载荷与这份独立答案逐字节一致，可确认该范围内的内容正确。 |

现场观察两类误读：第一轮把 `decoded` 或多次读出当成正确；第二轮只看到 `provided` 或“范围内通过”，没有定位逐字节比对结果。有答案还需检查实际比对结果；校验结论限于这张图、该区域和这份答案。

## 来源与复现

两份原始报告均由摄像头项目 `566fa53` 的 `src/analyze_label.py` 生成。图片来自 [stage2-known-qr.png](../../../../data/samples/stage2-known-qr.png)，独立答案来自[预先固定的文件](../../../../data/samples/stage2-known-qr.expected.txt)，来源记录见 [stage-2-roi-qr-baseline.md](../../../stage-2-roi-qr-baseline.md)。主持人已直接核对答案文件字节、答案摘要与解码载荷。助手导入后解释上游记录，答案来源在报告内标为 `user_asserted_independent`。

从摄像头仓库根目录复现，每次输出到新的临时目录：

```powershell
$dir = Join-Path ([IO.Path]::GetTempPath()) ('qr-trial-' + [guid]::NewGuid().ToString('N'))
$null = New-Item -ItemType Directory -Path $dir -ErrorAction Stop
$img = 'data/samples/stage2-known-qr.png'
.\.venv\Scripts\python.exe -B -X utf8 src/analyze_label.py $img --output (Join-Path $dir '01.json')
if ($LASTEXITCODE) { throw '第一轮分析失败' }
.\.venv\Scripts\python.exe -B -X utf8 src/analyze_label.py $img --expected-file 'data/samples/stage2-known-qr.expected.txt' --truth-source '项目合成样例生成前固定的 UTF-8 答案文件（stage2-known-qr.expected.txt）' --output (Join-Path $dir '02.json')
if ($LASTEXITCODE) { throw '第二轮分析失败' }
```
