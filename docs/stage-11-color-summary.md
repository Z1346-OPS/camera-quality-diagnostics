# Stage 11 按场景汇总颜色报告

## 目标与输入输出

读取已保存的带标签颜色 CSV，按场景汇总记录数、通道差平均值、最小值和最大值。输入为 `data/reports/camera_colors_labeled.csv`，输出为终端文本，不改写原始文件，不打开摄像头，不做偏色诊断。

## 关键流程与设计原因

`summarize_color_report()` 只读打开 CSV → 检查表头与行结构 → 检查标签和通道差 → 按标签累积数量、总和、最小值、最大值 → 用总和除以数量得到均值。`main()` 负责接收可选报告路径、打印汇总和明确报告错误。

使用字典分组与逐行读取，不需要安装 pandas，也不需要把所有记录存进列表。场景标签是分组依据；帧号会在不同运行中重置，不能当作全局分组键。

汇总基于 CSV 已保存的一位小数通道差，而不是从已舍入的 BGR 均值重新计算，避免把舍入差异误当成计算错误。只统计实际出现的标签；有表头但没有记录时提示暂无记录。

## 易错点与错误处理

- 汇总文件内所有记录，包括不同运行、光照和场景细节，尚不支持筛选某次运行。应在摄像头退出后汇总，避免读取正在追加的文件。
- 每组只有一条记录时，均值、最小值和最大值相等。这不证明场景稳定，也不是阈值标定。
- 旧无标签 CSV 会报表头不匹配；缺失文件、字段不完整、未知标签、非数字及非有限或超范围通道差会明确报错，不输出部分汇总。
- 本阶段只核验汇总所需的标签、通道差与行结构，不是对时间戳、帧号和 BGR 数据的全面审计。
- 当前尚无本阶段用户实测错误；不将测试中构造的坏输入写成真实故障。
