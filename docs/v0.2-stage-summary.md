# v0.2 基础图像质量指标阶段总结

## 1. 阶段目标

在已经能够稳定打开 USB 摄像头的基础上，把画面质量从“人眼感觉”转化为可显示、可测试、可保存的基础数字指标。

本阶段不自动判断设备故障，不设置工业场景通用合格阈值，也不开始 RAG 项目。

## 2. 已完成内容

| 能力 | 实现方法 | 当前输出 |
|---|---|---|
| 平均亮度 | 灰度图像素均值 | `brightness` |
| 欠曝比例 | 灰度值小于等于30的像素比例 | `dark` |
| 过曝比例 | 灰度值大于等于225的像素比例 | `bright` |
| 清晰度 | 拉普拉斯结果的方差 | `sharpness` |
| 对比度 | 全部灰度像素的标准差 | `contrast` |
| 灰度直方图 | 统计0–255每个灰度值的像素数量 | `hist peak` 和 `count` |
| 单帧报告 | 按 `s` 追加写入 CSV | 时间、帧号和五项质量指标 |

此外，程序支持摄像头多后端重试、读取失败提示、`q` 键退出，以及无论正常退出还是出现异常都释放摄像头资源。

## 3. 完整数据流

```text
USB 摄像头
    ↓ cap.read()
BGR 彩色帧
    ↓ cv2.cvtColor()
灰度帧
    ├─ 平均值 → 亮度
    ├─ 阈值计数 → 欠曝/过曝比例
    ├─ 拉普拉斯方差 → 清晰度
    ├─ 灰度标准差 → 对比度
    └─ 256级计数 → 直方图峰值和峰值计数
    ↓
实时画面叠加显示
    ↓ 按 s
CSV 单帧报告
```

## 4. 模块职责

- `src/camera_test.py`：打开摄像头、循环读取帧、显示指标、处理 `s` 和 `q` 按键、释放资源。
- `src/metrics.py`：检查图像输入并计算所有基础质量指标。
- `src/report.py`：创建报告目录并追加保存 CSV 数据。
- `tests/test_metrics.py`：使用人工图像验证指标计算。
- `tests/test_report.py`：验证报告目录创建、表头、追加写入、格式和时间精度。

这种结构延续方案 B：保留能运行的摄像头程序，把计算和保存逐步迁移到独立模块，而不是从头重写。

## 5. 真实验证证据

- 亮度：正常、遮挡和明亮场景产生不同的平均灰度结果。
- 曝光比例：把欠曝阈值从30临时改为90后，欠曝比例从 `1.7%` 上升到 `36.8%`，随后恢复阈值。
- 清晰度：清晰画面约230，眼镜遮挡后约70；修改拉普拉斯核后数值尺度明显变化，随后恢复。
- 对比度：单色白纸为 `21.9`，加入黑字后为 `33.3`；标准差临时改为方差后理解了平方关系，随后恢复。
- CSV：真实摄像头多次按 `s` 后只保留一个表头并追加多行数据；时间精度已从秒修改为毫秒。
- 直方图：人物场景峰值灰度232、峰值计数31025；单色纸峰值灰度136、峰值计数34256。
- 最近一次完整自动测试：`32 passed`。

## 6. 实际排障记录

### CSV 无法写入

现象：出现 `Permission denied`。

排查：文件存在且不是只读状态；关闭正在查看 CSV 的程序后，同一路径可以再次追加打开并正常保存。

结论：排查结果与 Windows 文件被其他程序占用相符。异常发生后，`finally` 仍正常释放摄像头。

### 按 `q` 没有响应

现象：直接按 `q` 时程序没有退出。

排查：切换英文输入法，并点击 OpenCV 画面使窗口获得键盘焦点。

结论：重新按 `q` 后正常退出，无需修改退出代码。

## 7. 当前局限

- 亮度、清晰度、对比度和直方图都会受到画面内容影响。
- 相机会自动调整曝光、增益和白平衡，遮挡镜头不一定得到全黑图像。
- 欠曝30和过曝225只是当前观察阈值，没有经过具体工业现场标定。
- 清晰度和对比度没有合格阈值。
- 直方图目前只显示峰值和计数，没有绘制完整曲线。
- CSV 保存用户主动选取的单帧，不是连续视频统计。
- 尚未实现噪声、脏污、条纹、马赛克或偏色故障识别。
- 尚未生成 JSON 报告，也没有开始 RAG、知识库或评测。

## 8. 四级掌握评价

- 一级（能看懂）：已达到。能够运行程序并观察各项指标。
- 二级（能自己解释）：已达到。能够区分亮度、曝光比例、清晰度、对比度和直方图峰值。
- 三级（能修改已有代码）：已达到。完成了阈值、格式、算法参数、时间精度和峰值计数等修改实验，并根据真实输出判断结果。
- 四级（能独立写类似逻辑）：暂未验证。

当前等级：v0.2 核心功能达到三级。

## 9. 面试表达

我使用 Python 和 OpenCV 开发了一个 USB 摄像头图像质量诊断工具。程序能够实时计算平均亮度、过曝和欠曝比例、拉普拉斯方差清晰度、灰度标准差对比度以及256级灰度直方图峰值，并把用户选取的单帧结果追加保存到 CSV。我使用人工图像编写自动测试，并通过白纸、文字、人物、遮挡和不同光照场景完成真实摄像头验证。在开发过程中还定位了 Windows 文件占用导致 CSV 无法写入，以及窗口焦点导致按键无响应的问题。目前项目完成的是基础指标和数据记录，阈值标定、自动故障识别和 RAG 诊断仍属于后续工作。

## 10. 下一步建议

下一阶段优先补充“读帧失败记录和报告状态”，让工具不仅能计算图像质量，也能记录采集链路是否稳定。完成后再选择一个简单故障方向继续，不同时开展多个识别算法。
