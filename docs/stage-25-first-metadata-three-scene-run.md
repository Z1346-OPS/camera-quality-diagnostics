## 易错点与下一步

与前两次 `unspecified` 批次相比，这次按键标签链路成功，但“标签正确”仍不等于“场景真实正确”。不能把 3 条同一运行的记录当成 3 次独立实验，也不能因亮度差较大就补写“光照变化”或“自动曝光变化”。原始 CSV 不改写。

下一步需更多条件明确的独立批次研究重复性，而不是直接用这次差值标定故障阈值。即使操作者报告光照和摄像头位置无变化，+40.1 的亮度差仍不能唯一归因于自动曝光、纸张摆放或其他因素。

练习：①什么证据证明两份 CSV 配对？②为什么 +40.1 不能说明自动曝光改变？③哪一项需要现场操作员确认、无法从 CSV 自动得知？
